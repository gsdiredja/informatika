# 🌐 kodi.web.id

Portal web statis dinamis berbasis **JAMstack / Serverless** yang di-host menggunakan **GitHub Pages** dan terintegrasi dengan **Google Apps Script** sebagai penyedia API/Backend.

---

## 🛠️ Teknologi yang Digunakan

* **Frontend:** HTML5, CSS3, JavaScript (Vanilla ES6)
* **Hosting Frontend:** [GitHub Pages](https://pages.github.com/)
* **Backend API:** [Google Apps Script](https://script.google.com/)
* **Database/Storage:** Google Sheets / Google Drive
* **Domain:** Custom Domain (`kodi.web.id`)
